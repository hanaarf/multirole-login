Modul Praktik Laravel / Multi-Role Authentication

Pengembangan Aplikasi Multi-Role.
Versi Laravel UI & Middleware.

Panduan lengkap step-by-step membuat autentikasi 2 role (Admin & User) berbasis laravel/ui Bootstrap, custom Middleware (isAdmin & isUser), Seeder, serta penyesuaian alur redirectTo.

Daftar Langkah Praktikum

LANGKAH 01-03 Inisialisasi Project, Setup .env & Install Auth UI

Jalankan perintah berikut di terminal untuk membuat project Laravel baru, mengonfigurasi database pada file .env, serta memasang paket autentikasi berbasis Bootstrap:

1. Buat Project Baru & Masuk ke Folder Project: 
composer create-project laravel/laravel multirole-app
cd multirole-app
2. Konfigurasi Database di file .env:

Buka file .env dan sesuaikan konfigurasi database berikut (sesuaikan nama database dan password MySQL Anda):

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=multirole_app
DB_USERNAME=root
DB_PASSWORD=
3. Install Package Auth (Laravel UI) & Frontend Dependency: 
# Install package laravel/ui
composer require laravel/ui

# Generate auth scaffolding dengan Bootstrap
php artisan ui bootstrap --auth

# Install & compile dependency frontend
npm install
npm run dev
LANGKAH 04 Ubah Migration User (Tambah Kolom Role)

Buka file migrasi tabel users dan tambahkan kolom enum untuk membedakan hak akses admin dan user.

File: database/migrations/xxxx_xx_xx_xxxxxx_create_users_table.php 
public function up(): void
{
    Schema::create('users', function (Blueprint $table) {
        $table->id();
        $table->string('name');
        $table->string('email')->unique();
        $table->timestamp('email_verified_at')->nullable();
        $table->string('password');
        
        // Tambahkan kolom role di sini (default: user)
        $table->enum('role', ['admin', 'user'])->default('user');
        
        $table->rememberToken();
        $table->timestamps();
    });
}

Jalankan migrationnya

Terminal: 
php artisan migrate
LANGKAH 05 Tambah 'role' ke Model User

Daftarkan atribut role ke dalam properti $fillable agar dapat diisi secara massal (mass assignment).

File: app/Models/User.php 
namespace App\Models;

use Illuminate\Foundation\Auth\User as Authenticatable;
use Illuminate\Notifications\Notifiable;

class User extends Authenticatable
{
    use Notifiable;

    protected $fillable = [
        'name',
        'email',
        'password',
        'role', // Added role field
    ];

    protected $hidden = [
        'password',
        'remember_token',
    ];
}

LANGKAH 09 Registrasi Alias Middleware di bootstrap/app.php

Daftarkan alias isAdmin dan isUser agar dapat dipanggil dengan mudah pada route.

File: bootstrap/app.php (Laravel 11 / 12) 
use App\Http\Middleware\AdminMiddleware;
use App\Http\Middleware\UserMiddleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    ->withMiddleware(function (Middleware $middleware) {
        // Registrasi alias middleware
        $middleware->alias([
            'isAdmin' => AdminMiddleware::class,
            'isUser'  => UserMiddleware::class,
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions) {
        //
    })->create();

LANGKAH 12 Isi Logika AdminMiddleware & UserMiddleware

Lengkapi logika pemeriksaan status login serta verifikasi nilai role pada masing-masing middleware.

File: app/Http/Middleware/UserMiddleware.php 
namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
use Symfony\Component\HttpFoundation\Response;

class UserMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        if (Auth::check()) {
            if (Auth::user()->role == 'user') {
                return $next($request);
            } else {
                return redirect('/');
            }
        } else {
            return redirect('/login');
        }
    }
}
File: app/Http/Middleware/AdminMiddleware.php

LANGKAH 13 Ubah LoginController (Redirection Logika Role)

Sesuaikan method redirectTo() di LoginController agar pengguna diarahkan secara otomatis ke halaman yang sesuai begitu selesai login.

File: app/Http/Controllers/Auth/LoginController.php 
namespace App\Http\Controllers\Auth;

use App\Http\Controllers\Controller;
use Illuminate\Foundation\Auth\AuthenticatesUsers;
use Illuminate\Support\Facades\Auth;

class LoginController extends Controller
{
    use AuthenticatesUsers;

    public function redirectTo()
    {
        if (Auth::user()->role == 'admin') {
            return route('admin.index');
        } elseif (Auth::user()->role == 'user') {
            return route('user.index');
        }
        
        return '/login';
    }

    public function __construct()
    {
        $this->middleware('guest')->except('logout');
    }
}
